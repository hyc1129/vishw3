
# 台灣國內航線營運分析 (115年9月) - 互動視覺化

這是一個以 D3.js 開發的互動式資料視覺化專案，結合了地理流向圖 (Flow Map)、矩形樹狀圖 (Treemap) 以及長條圖 (Bar Chart)，呈現台灣各機場在 115 年 9 月份的國內航線流量與載客率表現。

## 一、 專案特色與視圖介紹

本專案採用「多視圖連動 (Linked Views)」設計，三個視圖共享相同的資料狀態，並透過中央事件調度器 (Coordinated Dispatcher) 達成即時、流暢的互動體驗。

1.  **地理流向圖 (Flow Map - 左側)**
    *   **地理空間**：以台灣麥卡托投影 (Mercator) 呈現本島與外島位置（金門、馬祖、澎湖等）。
    *   **機場節點**：以圓點標示各航線的出發/目的地機場。
    *   **航線流向**：機場間的弧線代表航線，**線條粗細**映射該航線的「載客人數」。
2.  **目的地流量佔比 (Treemap - 右上)**
    *   **流量佔比**：以矩形面積呈現各機場的載客人數規模。
    *   **動態階層**：
        *   在**全域狀態**下，顯示各「出發機場」的總流量佔比。
        *   在**過濾狀態**下，下鑽顯示該機場前往各「目的地」的流量佔比。
    *   *註：為了讓長尾極端值（如望安、七美等小機場）也能清晰顯示並提供點擊互動，面積運算採用了 0.3 次方 (`Math.pow`) 進行壓縮。*
3.  **航線載客率排行 (Bar Chart - 右下)**
    *   **營運效率**：以長條長度呈現各航線的「載客率 (%)」。
    *   **動態排序**：過濾機場時，會自動重新計算 Y 軸並由高至低重新排序。

## 二、 互動操作指南

### 1. 全域 Hover 連動 (Selection + Highlighting)
*   **操作方式**：將滑鼠游標停留在任一視圖的資料元素上（地圖的航線/機場、樹狀圖的方塊、長條圖的柱子）。
*   **視覺反饋**：
    *   三個視圖中與該航線（或該機場）相關的元素會保持**高亮 (完全不透明)**。
    *   其餘不相關的元素會瞬間**弱化 (透明度降至 15%)**，幫助您專注於當下關注的數據。
*   **細節提示框 (Tooltip)**：滑鼠停留時，游標旁會浮現半透明的黑色提示框，顯示該航線或機場的精確數據（載客人數、載客率、飛行架次）。

### 2. 動態過濾與下鑽 (Dynamic Filtering)
*   **操作方式**：
    *   點擊地圖上的「機場圓點」。
    *   點擊樹狀圖（全域狀態下）的「機場方塊」。
*   **視覺反饋 (轉場動畫)**：
    *   **地圖**：只保留與該機場相連的出發/抵達航線，其餘航線隱藏。
    *   **樹狀圖**：流暢地放大下鑽，原本的全台機場分佈會轉變為「該機場前往各目的地」的流量佔比。
    *   **長條圖**：動態過濾出與該機場相關的航線，並重新由高至低排序。

### 3. 取消選取 / 回到全域 (Reset Filter)
本專案採用隱含操作設計，保持介面簡潔：
*   **方法 A (Toggle)**：再次點擊「已經被選取」的機場圓點或樹狀圖方塊。
*   **方法 B (Background Click)**：點擊地圖視圖中的任何空白處（陸地或海洋）。
*   執行上述操作後，三個視圖皆會透過動畫平滑過渡，恢復為預設的全台總覽狀態。

### 4. 無障礙鍵盤操作 (Accessibility)
所有可互動元素均支援鍵盤操作：
*   按 `Tab` 鍵可在地圖航線、機場節點、樹狀圖與長條圖之間切換焦點（會出現藍色外框）。
*   游移至元素時，會觸發如同滑鼠 Hover 的三方連動與 Tooltip 顯示。
*   按下 `Enter` 鍵等同於滑鼠點擊，可觸發機場的動態過濾。

## 三、 色彩計畫與視覺層次

*   **核心分類色**：採用 D3 內建的 `Tableau10` 專業色系，並綁定於「出發機場」。在不同視圖中，相同顏色的元素皆代表來自同一個機場的航線，降低使用者的認知負載。
*   **預設微透明度**：資料圖形預設給予 85% 的不透明度，保留輕微透視感，減輕大面積色塊的視覺疲勞。
*   **乾淨底圖**：地圖陸地使用淺灰色 (`#e2e8f0`) 搭配純白邊界，確保資料層（航線）成為絕對的視覺焦點。

## 四、 本機執行與測試方式

因 D3.js 讀取外部檔案 (`d3.json`) 受到瀏覽器安全性 (CORS) 限制，**請勿直接雙擊開啟 `index.html`**。

請依照以下步驟在本地端啟動專案：

1.  確保 `index.html`、`main.js`、`counties-10t.json`、`d3_flow_map.json` 放在同一個資料夾內。
2.  **方法一 (推薦，使用 VS Code)**：
    在 VS Code 安裝 `Live Server` 擴充功能，對著 `index.html` 點擊右鍵選擇 "Open with Live Server"。
3.  **方法二 (使用 Python)**：
    打開終端機 (Terminal) 進入該資料夾，輸入 `python -m http.server 8000` (Mac/Linux 使用 `python3`)。接著打開瀏覽器，前往 `http://localhost:8000` 即可檢視視覺化成果。
